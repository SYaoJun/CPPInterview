# Audio-Video Processing

Technical Requirements for C++ Audio-Video Developer

## Core Skills

### C++ Programming
- Modern C++ (C++11/14/17/20) features
- Low-level memory management and buffer handling
- SIMD optimization (SSE, AVX, NEON)
- Zero-copy memory operations
- Lock-free data structures

### Video Codecs
- H.264/AVC, H.265/HEVC encoding/decoding
- VP8, VP9, AV1 codec implementation
- FFmpeg library integration
- Hardware acceleration (NVENC, QuickSync, VAAPI)
- Rate control and quality optimization

### Audio Processing
- AAC, Opus, MP3 encoding/decoding
- Audio resampling and mixing
- Noise suppression and echo cancellation
- Real-time audio streaming
- FFmpeg/libav audio pipeline

### Streaming Protocols
- RTMP (Real-Time Messaging Protocol)
- HLS (HTTP Live Streaming)
- DASH (Dynamic Adaptive Streaming)
- WebRTC for real-time communication
- RTP/RTSP protocols

## Tools & Technologies

### Multimedia Frameworks
- FFmpeg (core multimedia framework)
- GStreamer pipeline development
- DirectShow/MediaFoundation (Windows)
- AVFoundation (macOS/iOS)
- V4L2 (Linux video capture)

### Graphics & Rendering
- OpenGL/Vulkan for video rendering
- OpenGL ES for mobile platforms
- Hardware overlay and composition
- Color space conversion (YUV, RGB)
- HDR and wide color gamut support

### Performance Optimization
- GPU acceleration (CUDA, OpenCL)
- Multi-threaded encoding pipelines
- Memory pool allocators
- Frame buffer management
- Cache optimization techniques

## Domain Knowledge
- Digital signal processing (DSP)
- Psychoacoustic models
- Video quality metrics (PSNR, SSIM, VMAF)
- Synchronization (audio/video lip sync)
- Container formats (MP4, MKV, FLV, TS)
